## Instructions

You might want to try a few samples.
For this, <span class='amber'>open a new tab (+)</span> and click "Samples", then load one of your choice.

Go back to the code tab, and see the blocks that got loaded in.
Now you can press <span class='teal'>“Run”</span> on the top navigation bar, and see the action take place either with a direct prompt to you, or in the console.

## What's it for

It was primarily here to test if what is now being built for [Graplet V4](/blog/graplet) is possible,
and a fun little experiment, where you can drag around coding blocks and kick off some interactions.

### Collatz conjecture sample

I'd reccomend you try the collatz conjecture, it's kinda fun.  
It shows [an unsolved math problem](https://en.wikipedia.org/wiki/Collatz_conjecture#:~:text=The%20Collatz%20conjecture%5Ba%5D%20is%20one%20of%20the%20most%20famous%20unsolved%20problems%20in%20mathematics.%20The%20conjecture%20asks%20whether%20repeating%20two%20simple%20arithmetic%20operations%20will%20eventually%20transform%20every%20positive%20integer%20into%201#), that by a specific repeated
pattern, deciding on whether it is even or not, you will always end up with `1`. To try this yourself,
you can change the number in the "collatz conjecture with" block.

`Q` : Why isn't it solved yet?  
`A` : Because no one could prove that it's always the case for all numbers.
